# SynapseMax — Front Prototype v6

Финальный визуальный штрих перед следующей итерацией.

- Исходный знак S остаётся полностью статичным.
- Убрана внутренняя синоптическая анимация, не совпадавшая с геометрией внутреннего контура.
- Вокруг знака добавлено орбитальное поле с эллиптическими трассами и электрическими нейронными точками, движущимися по самим контурам.
- Есть мягкие cyan/violet импульсы и короткие световые хвосты.
- Сохранены адаптивная разметка, бренд-ассеты, кейсы, подход, AI Lab и mobile navigation.

## Запуск

Открыть `index.html` в браузере.
