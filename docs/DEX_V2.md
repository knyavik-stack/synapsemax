# SynapseMax — DEX v2

## Цель

DEX v2 — визуальная итерация сайта после принятого Front baseline. Цель — сделать HUD/FUI не декоративным слоем, а понятным языком состояния и преобразования бизнеса.

## Главный принцип

**Сложность → связь → система → действие → результат.**

Пользователь должен понимать идею SynapseMax даже без знания терминов AI.

## Изменения относительно DEX v1

- Русские названия разделов вместо англоязычных заголовков.
- Убраны чрезмерные вертикальные пустоты между секциями.
- В шапке используется канонический wordmark из брендовых assets, а не случайный шрифт.
- Возвращены и усилены неоновые иконки раздела «Решения».
- «Подход» превращён в смысловую анимацию: хаотичные узлы сходятся к центральному Synapse-ядру и выходят в структурированный контур.
- «Кейсы» получили живые мини-визуализации вместо пустых карточек.
- Телеметрия вынесена из зоны заголовков и не должна перекрывать смысловой текст.
- Анимации стали медленнее и многослойнее; движение должно читаться как поток данных, а не как декоративное мерцание.
- Сохранён канонический S-знак: части логотипа не разрезаются и не деформируются.

## Типографика

Wordmark не заменяется web-шрифтом. Для интерфейсной типографики используется связка **Exo 2 + Manrope**: Exo 2 задаёт технологический характер заголовкам, Manrope сохраняет читаемость длинного текста.

## Validation gates

Перед переводом в production:

1. Desktop: 1440×900 и 1920×1080 — нет перекрытий, ритм секций равномерный.
2. Mobile: 390×844 и 430×932 — нет горизонтального overflow и потери иконок/CTA.
3. Hero: логотип и окружающая анимация не закрывают текст.
4. Подход: визуально считывается преобразование хаоса в систему без объяснения голосом.
5. Решения: все три иконки видимы и имеют смысловую связь с карточкой.
6. Кейсы: каждая карточка содержит живой объект, а не декоративный placeholder.
7. Accessibility: `prefers-reduced-motion` отключает тяжёлую анимацию.
8. Deployment: Cloudflare Build должен завершаться зелёным до любого production release.

## Архитектура

`GitHub → build-site.mjs → dist → Cloudflare Assets → Worker → dex-v2.html`

DEX v1 сохраняется как исторический baseline для сравнения. Worker показывает DEX v2 на `/`.
