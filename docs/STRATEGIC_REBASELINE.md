# Strategic Rebaseline — Immediate

SynapseMax is the first interface of a future Transformation Intelligence Platform, not an AI showcase.

Core chain: `Complexity → Understanding → System → Automation → Outcome`.
Operational loop: `Diagnose → Design → Simulate → Automate → Monitor`.

H1 must become a first product experience: Transformation Assessment → Complexity Profile → As-Is/To-Be process model → ROI hypothesis → contextual AI Consultant.

Architecture boundary: `Experience → Domain Logic → API → future Intelligence Layer`.

H1 calculations are deterministic intentionally. They are a replaceable seam for future diagnostics, process mining, simulation and AI services; they do not pretend that those services already exist.

Acceptance gate: verify exact commit → build → domain/API smoke → browser runtime → desktop/mobile visual QA → regression → merge.
